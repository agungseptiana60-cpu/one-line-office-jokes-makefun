One funny line, whole on its own: I finally learned to say no in meetings, so now they schedule a follow-up meeting to discuss why I said no. The program in `main.ts` writes that single line (107 characters) to `entry.txt` in the output directory, after checking it fits the 1–199 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
